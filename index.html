Backup e privacy

Il sito è statico: i dati finanziari e le checklist sono salvati in localStorage sul dispositivo/browser, non in un database cloud. Se cancelli i dati del browser, potresti perderli.

Per usare il sito su più dispositivi, serve un sistema di sincronizzazione autenticato: GitHub Pages pubblica il sito ma non sincronizza i dati personali.

Come pubblicare il sito

Il codice viene versionato su GitHub. Per renderlo accessibile online, abilita GitHub Pages nelle impostazioni del repository: Settings → Pages → Deploy from a branch → main → /(root) → Save.
